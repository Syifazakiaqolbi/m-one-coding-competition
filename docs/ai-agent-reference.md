# AI Agent Reference — M-ONE Coding Competition

## 1. Tujuan Proyek
Membangun website edukasi coding untuk anak SD (6–12 tahun) yang:
- Informatif, kreatif, aplikatif
- Mendukung tema "Innovating Education Through Technology"
- Subtema: Web Education for Kids (SD)

## 2. Stack Teknologi
- Framework: React + Vite
- Styling: Tailwind CSS
- Animasi: Framer Motion
- Ikon: Lucide React
- Hosting: Vercel
- AI Tools: DeepSeek

## 3. Fitur Utama
1. Landing page — hero, about, features, testimonials, CTA
2. Materi belajar — HTML, CSS, JavaScript dasar
3. Quiz interaktif — pilihan ganda, feedback, skor, badge
4. Playground kode — editor + live preview
5. Progress tracking — localStorage, poin, badge
6. Fitur inovasi — [TENTUKAN NANTI]

## 5. Aturan Kerja AI Agent
- Selalu jelaskan alasan sebelum memberikan kode
- Kode modular, reusable, responsif
- Gunakan semantic HTML dan SEO dasar
- Commit message rapi: feat, fix, docs, style, refactor, chore
- Optimasi performa: lazy load, kompresi aset, minimal dependency
- Target Lighthouse > 90

## 6. Definition of Done
- Semua fitur berjalan tanpa error
- Responsif di mobile & desktop
- Website ter-deploy dan bisa diakses
- Dokumentasi lengkap
- Commit history rapi

## 7. Target Audiens
Anak SD (6–12 tahun) — bahasa sederhana, visual menarik, warna cerah, tombol besar.
